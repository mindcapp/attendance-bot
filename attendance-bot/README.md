# Attendance Bot ИСПО СПбПУ

Telegram-бот для отметки посещаемости группы: выбор номера, статус (пришёл / опоздает / не придёт / по уважительной / задержится), запись явок в CSV и отчёт по дню — таблицей в чате или файлом Excel.

## Что нужно

- Go 1.26+ (см. `go.mod`)
- Токен бота от [@BotFather](https://t.me/BotFather)

## Запуск

```bash
cp .env.example .env        # вписать свой TELEGRAM_BOT_TOKEN
go mod download
go run .
```

Или собрать бинарник:

```bash
go build -o attendance-bot .
./attendance-bot
```

Запускать нужно из корня проекта — пути `data/students.json` и `attendance.csv` относительные (их можно переопределить через `STUDENTS_FILE` и `ATTENDANCE_FILE` в `.env`).

## Как пользоваться

1. `/start` или `/attendance` — бот показывает меню: **«Отметить явку»** и **«Просмотреть отчёт»**.

### Отметить явку

1. Выбрать свой номер (кнопки по 3 в ряд).
2. Выбрать статус:
   - **✓ Пришёл** / **✗ Не приду** / **📋 По уважительной** — сразу записывается.
   - **⏰ Опоздаю** — дополнительно спросит «Ко скольки паре?» (1–5).
   - **⏳ Задержусь** — спросит, на сколько минут (5, 10, 15, 20, 30, 60), затем «Ко скольки паре?».
3. Итог: `✓ Статус записан: Опоздаю ко 2 паре [14:50]`.

Если такого номера нет — «Номер не найден, попробуй ещё». Повторная отметка того же номера в тот же день не дублирует запись — она заменяет предыдущий статус.

### Просмотреть отчёт

- **📊 Таблица в чате** — форматированная таблица за сегодня прямо в сообщении.
- **📁 Скачать Excel** — файл `.xlsx` с колонками Номер / ФИ / Статус / Время отметки / К какой паре, жирный заголовок, границы, выравнивание по центру.

Если явок за сегодня ещё нет — бот так и скажет, файл не создаётся.

## Список студентов

`data/students.json`:

```json
[
  { "number": 1, "name": "Анна Иванова" },
  { "number": 5, "name": "Иван Сидоров" }
]
```

Номера должны быть уникальными и положительными. После изменения файла перезапусти бота.

## Формат attendance.csv

```csv
date,time,number,name,status,para,delay_minutes
2026-09-30,14:32,5,Иван Сидоров,Пришёл,-,0
2026-09-30,14:50,2,Петр Иванов,Опоздаю,2,0
2026-09-30,14:35,3,Анна Кузнецова,Задержался на 10 минут,1,10
```

Время берётся по локальному часовому поясу машины, где запущен бот (можно задать через `TZ`, например `TZ=Europe/Moscow go run .`).

## Структура

```
main.go                  инициализация бота, цикл обновлений
config/config.go         чтение .env
handlers/start.go        /start, /attendance, главное меню, роутинг callback-ов, состояние диалога
handlers/attendance.go   выбор номера, статус, задержка, пара — вся логика отметки явки
handlers/report.go       отчёт: таблица в чате и генерация Excel
storage/students.go      загрузка студентов из JSON
storage/attendance.go    чтение/запись явок в CSV (с заменой статуса за тот же день)
excel/export.go          генерация XLSX-отчёта (github.com/xuri/excelize/v2)
data/students.json       список студентов
```

## Ошибки при старте и в рантайме

- `TELEGRAM_BOT_TOKEN не задан` — нет `.env` или переменная пустая.
- `Не удалось подключиться к Telegram — проверь TELEGRAM_BOT_TOKEN` — токен невалидный (или нет сети).
- `Номер не найден, попробуй ещё` — введён/выбран номер, которого нет в `data/students.json`.
- `Ошибка при создании файла` — не удалось сгенерировать или отправить Excel-отчёт (подробности — в логе бота).
